## Что изменено

- **089–093:** обязательный notifier вместо optional-конфликта конструктора; сериализация refresh/initial load/delete;091 объединена с090; безопасная инициализация IsExpanded без виртуального вызова из base ctor; реальные контракты HTTP doubles и тест миграции цен на SQLite.
- **094–104:** исследование использует экземпляр navigation из DI, не статический API;095 выбирает один SafeAreaEdges-механизм с ответом на историческое «через стиль»;096 учитывает позднюю цену;097/098 имеют явные зависимости и layout/lifecycle guards;099 валидирует настоящие stable теги/читает snapshots;100 проверяет PE machine, не размеры zip;103 разбирает многострочные XAML-теги;104 остаётся узким удалением неиспользуемой декларации.
- **106–109,124:** polling catch отделён от обработки результата; missing provider отличается от connection без очереди; точные start leases/stop signals/launch gates и race tests; timeout на send+body; валидаторы callback; redirect policy проверяется по реальной DI handler chain, probe сохраняет ApiKeyStatus contract.
- **102,111–113,121–122,125–130:** отдельные контракты adapter/router/dispatch;128 не меняет production-dispatch до129; один semaphore на provider, не двойной;121 не теряет поздний handle при delete;125 повторяет только подтверждённые transient UPDATE;129 переносит CostUsd, обновляет все interface/double call sites. Компенсация122 охватывает только failed UPDATE после полученного file path, исключение подписчика после успешной записи не удаляет подтверждённый файл.
- **110,114,123,127:** точные формулы/rounding и raw estimate; ContextBudget остаётся для summary; backward-compatible logger helper; атомарный user+attachments commit с SQLite rollback-тестом; pre/post-accept границы; ошибка wire оформляется существующим ProviderException.127 устраняет чтение body до bounded parser, различает request/response, обновляет normative logging guidance новым ADR.
- **112/127:** JSON8MiB, generated-image JSON72MiB, binary image50MiB; большой b64_json не режется обычным JSON cap. Общие BodyKind/SkipResponseBody; Information не читает body, Debug/trace bounded. Эти числа — проектные пределы плана, не измерение реальных API.
