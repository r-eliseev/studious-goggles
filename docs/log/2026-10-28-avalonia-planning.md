# 2026-10-28: планирование третьей оболочки на Avalonia

## Решения владельца
Ответы на пять вопросов (заданы по одному): десктоп Linux, Windows, macOS; MAUI остаётся на всех своих платформах (на Windows и macOS две оболочки); общий проект `ImageGen.Presentation` для логики экранов; ключи в системных хранилищах (DPAPI, Keychain, Secret Service), без них — только в памяти; работа сразу после задачи 035.

## Что сделано
- ADR 0006 (`docs/decisions/0006-avalonia-desktop-and-presentation.md`, принято).
- Задачи backlog 038 (вынос `ImageGen.Presentation`), 039 (пустое Avalonia-приложение, headless-тесты, CI), 040 (ключи в системных хранилищах, с пробным кодом для Secret Service), 041 (навигация, диалоги, ключ, список сессий), 042 (чат, карточки, модели сессии) — планы, статус `planned`.
- Очередь в `docs/status.md`: 035 → 038 → 039 → 040/041 → 042 → 036 → … Зависимости 018, 019, 020, 027, 036 дополнены (после 038 модели страниц в Presentation, экранная часть в обеих оболочках).
- `docs/architecture.md` («Целевая раскладка», правила слоёв, ограничения), `docs/product.md` и `docs/status.md`: решение «Linux отложен» пересмотрено.

## Факты (nuget.org, 2026-10-28)
- Avalonia 12.1.4, обновлено 2026-10-09, цели `net8.0` и `net10.0`.
- `Avalonia.Headless.XUnit` 12.1.4 зависит от `xunit.v3.extensibility.core` (>= 3.2.2); совместимость с версией xUnit v3 в проекте не проверена.

## Ответы владельца
- macOS-части делаются без проверки, с пометкой «не проверено».
- У MAUI и Avalonia на одной Windows-машине разные папки данных.
