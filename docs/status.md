## Открытые вопросы
- Бесплатных моделей картинок у OpenRouter на 2026-10-27 нет; модель по умолчанию — `black-forest-labs/flux.2-klein-4b` ($0.014 за мегапиксель, есть seed). Модель ассистента по умолчанию — `anthropic/claude-haiku-5.5` (`SessionSettings.cs:10`).
- Цена моделей fal (задача 093): в списке моделей цены нет, `GET https://api.fal.ai/v1/models/pricing` без ключа отвечает 401, форма ответа неизвестна; у fal показывается «price unknown». Проверить с ключом fal.
- Формы API, которые проверяются только на заглушках (задача 036): ответ `images/generations` у OpenAI-совместимых сервисов (берётся `data[0].b64_json`, ответ с URL не поддержан; `response_format`/`output_format` настраиваются по ADR 0023); заголовок `anthropic-version: 2023-06-01` и `GET /models` у Anthropic-совместимых сервисов. Неизвестно, совпадают ли они с реальными сервисами: проверить вручную на реальном ключе (`docs/decisions/0009-provider-config-and-model-ref.md`).
- Описание картинки (задача 019): ответ модели с картинкой на живом OpenRouter и цена описания не проверены (ADR 0013); неудачные chat completions тарифицируются ли — неизвестно.
- Вложения (задача 018): форма `input_references` в `POST /api/v1/images` проверена только заглушкой (допущение владельца, ADR 0012); согласие F10.6 хранится в памяти экрана чата; миниатюры вложений в ленте не показываются.
- Параметры генерации (задача 020): форма тела `POST /api/v1/images` для `aspect_ratio`, `resolution`, `output_format`, `quality` проверена только заглушкой (допущение владельца, ADR 0011). Единица значений `512` и `768` у разрешения не подтверждена.
- Журнал (задача 045): путь папки логов Avalonia на macOS не проверен (Windows проверен 2026-10-28) (`docs/knowledge/dev-environment.md`, «Логи»; ADR 0010).
- Avalonia MAUI Backend (`Avalonia.Controls.Maui`) запускает MAUI-код на Linux и в браузере, но на 2026-10-28 это предрелиз под .NET 11 с ограничениями ровно в наших API: не берём (`docs/knowledge/avalonia-maui-backend.md`). Пересматривать ли ADR 0006 после стабильного выпуска для .NET 11 и перехода проекта на .NET 11 — решает владелец; допущение — две оболочки остаются.
- Запуск приложения с неверным `providers.json` (сообщение об ошибке и остановка старта) проверен тестом композиции, но не в окне MAUI и Avalonia.

- Поиск по смыслу (ADR0016,105): offline mode исключён. Нужно решить: старые записи индексировать сразу при включении или в фоне; как подтверждаются передача истории и платные embeddings, лимит/остановка; отдельный semantic режим или смешивание с fuzzy; поддерживаемый размер индекса/памяти. Качество bge-m3 и стоимость в возвращаемых API units не измерены. Существующий SearchText не имеет source id/version — это обязательный контракт будущего плана, не решённая реализация.
- Задача030: ApplicationId уже утверждён `com.eliseev.imagegen`. Владелец задаёт точные Publisher/PublisherDisplayName, одобряет иконку/заставку и выбирает перенос существующих MAUI Windows/Android данных/ключей либо новый профиль с повторным вводом. Фактический путь Windows unpackaged приложения надо измерить; новая Android sandbox не получает автоматический доступ к старой. Windows manifest/migration планируются отдельно.
- Together AI: встроенный image-only provider с каталогом FLUX; официальный контракт/цены сверены по документации 2026-10-30. Live paid response, доступность по аккаунту и фактическое списание не проверялись; `CostUsd` остаётся неизвестным.

- OS fullscreen MAUI iOS/MacCatalyst: кто предоставляет совместимую macOS/Xcode-среду и проверку устройства? До отдельного проверяемого плана сохраняется modal viewer131, поддержка OS fullscreen на этих платформах не заявляется.
- Выбор мобильной оболочки (задача 094, ADR 0019, предложено): A, B или C — решает владелец. Android APK Avalonia собирается и на 6.65 МиБ больше MAUI; запуск, Android Keystore, клавиатура и TalkBack не проверены без устройства. iOS изучена только по документации.

## Решения владельца (2026-10-29, ADR 0016 / задача 081)
- Картинки провайдеру эмбеддингов для индексации: нет, только текст (см. решение выше о провайдере картинок).
- Модель текста для поиска по смыслу: `baai/bge-m3`.
- Провайдер картинок для поиска по смыслу: `gemini-embedding-2`. Противоречит первому решению: картинки для этого провайдера отправляются только если картинки отправляются. Нужно уточнить: провайдер картинок не используется вовсе (тогда выбор снимается), или картинки всё же индексируются с согласием. Снято 2026-10-29: картинки не отправляются, ADR 0016 принят (раздел выше).
- Офлайн-режима semantic search не будет: локальные embedding-модели, ONNX Runtime, веса и fallback без сети не добавляются. Стратегия переиндексации старых данных пока не решена.

## Известные проблемы
