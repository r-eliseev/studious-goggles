## Решения владельца (2026-10-27)
- Linux: отложено. MAUI Linux не поддерживает, оставляем как есть; допущение «Linux обслуживает Web-оболочка» сохраняется до пересмотра.
- Репозиторий результатов: локальная БД + файлы за интерфейсом в Core (на сервере то же самое в томе Docker).
- Img2Text: входит в первую версию; это генерация текстового описания или промпта по готовой картинке (в спецификации F4.9).
- Syncfusion.Maui.Toolkit: лицензия MIT (по странице репозитория github.com/syncfusion/maui-toolkit, 2026-10-27). Пока не используем; когда понадобятся такие контролы (графики расходов, shimmer, pull-to-refresh), это первый выбор, если нет ничего лучше.
- Web-авторизация: пароль из переменной окружения, форма входа (cookie-сессия). Приложение однопользовательское.
- Ключи в Web/Docker-оболочке: файл секретов, зашифрованный через ASP.NET Core Data Protection, ключи шифрования в томе Docker (принято).
- Не входит в первые версии: синхронизация между устройствами, видео, LoRA, локальные модели (ComfyUI). Пользователь всегда один.
- Вопросы платформы и хранения из раздела «Открытые вопросы» спецификации закрыты этими решениями и решениями выше (Linux отложен).

## Известные проблемы
- В проекте-примере `ApplicationId` равен `com.companyname.imagegen`, в `Package.appxmanifest` placeholder-значения издателя. Заменить до релиза.
- В проекте-примере модели хранят UI-типы (`Brush`, `Color`), поэтому не переносятся в Core как есть.
- Файл `ImageGen/ImageGen/Data/TaskRespository.cs` назван с опечаткой (класс `TaskRepository`).
- В `ImageGen.Core` все интерфейсы объявлены `internal`: MAUI-проект и будущая Web-оболочка их не увидят (нужен `public` или `InternalsVisibleTo`). В `IImageToText.cs` интерфейс назван `IImangeToText` (опечатка).
- Тестовых проектов нет, `dotnet test` ничего не проверяет.
- Не проверено: сборка `dotnet build ImageGen/ImageGen.slnx` в этой сессии не запускалась (требует MAUI-нагрузок).
