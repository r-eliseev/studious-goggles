## Открытые вопросы
- Linux: .NET MAUI не поддерживает Linux официально (target frameworks шаблона: android, ios, maccatalyst, windows). Заметки просят «Win / Linux / MacOS». Чем закрывать Linux: Web API + Vue в браузере, стороннее решение на MAUI, другой UI-стек? Допущение пока: Linux обслуживает Web-оболочка.
- Img2Text есть в заметках и нет в спецификации. Что это: описание картинки в промпт (для расширения промпта и референсов)? Входит ли в первую версию? Допущение пока: нет, только заготовка в ядре.
- «Свой репозиторий результатов»: что имеется в виду: локальная БД и файловое хранилище, отдельный сервис, git-репозиторий? Допущение пока: локальное хранилище (БД + файлы) за интерфейсом, чтобы реализацию можно было заменить.
- Web-авторизация: один общий пароль из env для всех запросов? Вход по форме с сессией или Basic? Допущение пока: единый пароль из переменной окружения, вход по форме с cookie-сессией; не принято.
- Где хранятся ключи в Web/Docker-оболочке: в MAUI это `SecureStorage`, на сервере его нет. Допущение пока: файл секретов, зашифрованный через ASP.NET Core Data Protection, том Docker для ключей шифрования. Не принято.
- Открытые вопросы спецификации (раздел «Открытые вопросы» в `docs/specs/image-client.md`): платформа частично закрыта заметками, остальные остаются (хранение с синхронизацией, видео и LoRA, число пользователей, ComfyUI).
- Пакеты проекта-примера: нужен ли в продукте `Syncfusion.Maui.Toolkit` (в примере из него графики, shimmer, pull-to-refresh, text input layout)? Лицензию не проверяли. Допущение пока: в новый код его не переносить, пока владелец не решил (см. `docs/conventions.md`).
