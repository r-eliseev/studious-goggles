## Открытые вопросы
- Avalonia-тесты закреплены на xunit v3 3.2.2 (`VersionOverride` в `ImageGen.Avalonia.Tests`): `Avalonia.Headless.XUnit` 12.1.4 не работает с xunit v3 4.0.2. Принять обход или выбрать общую версию — см. `docs/decisions/0007-avalonia-tests-xunit-3-2.md` (задача 039, «Комментарии»).
- Бесплатных моделей картинок у OpenRouter на 2026-10-27 нет; модель по умолчанию — `black-forest-labs/flux.2-klein-4b` ($0.014 за мегапиксель, есть seed). Бесплатная модель только у ассистента: `google/gemma-4-31b-it:free`.

- Формы API, которые проверяются только на заглушках (задача 036): ответ `images/generations` у OpenAI-совместимых сервисов (берётся `data[0].b64_json`, ответ с URL не поддержан); заголовок `anthropic-version: 2023-06-01` и `GET /models` у Anthropic-совместимых сервисов. Неизвестно, совпадают ли они с реальными сервисами: проверить вручную на реальном ключе (`docs/decisions/0009-provider-config-and-model-ref.md`).
- Описание картинки (задача 019): ответ модели с картинкой на живом OpenRouter и цена описания не проверены (ADR 0013); неудачные chat completions тарифицируются ли — неизвестно.
- Вложения (задача 018): форма `input_references` в `POST /api/v1/images` проверена только заглушкой (допущение владельца, ADR 0012); согласие F10.6 хранится в памяти экрана чата; миниатюры вложений в ленте не показываются.
- Параметры генерации (задача 020): форма тела `POST /api/v1/images` для `aspect_ratio`, `resolution`, `output_format`, `quality` проверена только заглушкой (допущение владельца, ADR 0011). Единица значений `512` и `768` у разрешения не подтверждена.
- Журнал (задача 045): путь папки логов Avalonia на Windows и macOS не проверен (`docs/knowledge/dev-environment.md`, «Логи»; ADR 0010).
- Запуск приложения с неверным `providers.json` (сообщение об ошибке и остановка старта) проверен тестом композиции, но не в окне MAUI и Avalonia.

## Решения владельца (2026-10-27)
- Ответы на вопросы по backlog (2026-10-28): порядок — раздел «Порядок работ»; планы 017–020, 025–027, 036 одобрены без ожидания 016; неизвестные формы API (параметры и референсы OpenRouter, ответы fal и Replicate) реализуются по допущению и проверяются вручную после реализации; детали — в «Комментариях» задач. Задача 037 отменена (входит в 036). `ApplicationId` = `com.eliseev.imagegen` (задача 030).
- ADR 0001 (общее ядро и оболочки MAUI и Web) принят 2026-10-28.
- ADR 0006 (2026-10-28): третья оболочка — Avalonia-десктоп (Linux, Windows, macOS); MAUI остаётся на всех своих платформах; общий слой представления `ImageGen.Presentation`; ключи в системных хранилищах, без них — только в памяти; работа сразу после 035.
- macOS-части (сборка, Keychain) делаются по документации с пометкой «не проверено», пока нет macOS-машины; у MAUI и Avalonia на одной Windows-машине разные папки данных и ключи (2026-10-28).
- ADR 0003 (контракт провайдера) принят 2026-10-28 с уточнением ADR 0005: OpenRouter тоже работает как задание в фоне, статус всех провайдеров — общий опрос.
- Скрипты задач пишут занятость и новые задачи в текущую ветку (`scripts/tasks-lib.sh`, PR #7), а не в `main`; документация харнеса переписана под это (`docs/harness.md`, «Параллельная работа»).
- Linux: пересмотрено 2026-10-28 — Linux-десктоп обслуживает Avalonia-оболочка (ADR 0006); Web-оболочка остаётся для браузера и Docker.
- Репозиторий результатов: локальная БД + файлы за интерфейсом в Core (на сервере то же самое в томе Docker).
- Img2Text: входит в первые версии (не в скелет); это генерация текстового описания или промпта по готовой картинке (в спецификации F4.9).
- Syncfusion.Maui.Toolkit: лицензия MIT (по странице репозитория github.com/syncfusion/maui-toolkit, 2026-10-27). Пока не используем; когда понадобятся такие контролы (графики расходов, shimmer, pull-to-refresh), это первый выбор, если нет ничего лучше.
- Web-авторизация: пароль из переменной окружения, форма входа (cookie-сессия). Приложение однопользовательское.
- Ключи в Web/Docker-оболочке: файл секретов, зашифрованный через ASP.NET Core Data Protection, ключи шифрования в томе Docker (принято).
- Не входит в первые версии: синхронизация между устройствами, видео, LoRA, локальные модели (ComfyUI). Пользователь всегда один.
- Вопросы платформы и хранения из раздела «Открытые вопросы» спецификации закрыты этими решениями и решениями выше (Linux отложен).
- Доступ к БД: SQLite через ADO.NET и свои миграции (`docs/decisions/0002-sqlite-ado-net.md`).
- Основной сценарий — сессии с ассистентом; первая версия — ходячий скелет на OpenRouter, только MAUI, базовый язык английский (`docs/specs/chat-sessions.md`, ADR 0004). Решение «сначала ядро на трёх провайдерах» отменено.
- Тесты: xUnit v3 и NSubstitute (владельцу всё равно, выбрано по ADR 0004).
