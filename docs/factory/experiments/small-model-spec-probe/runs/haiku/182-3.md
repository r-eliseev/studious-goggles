**ASSUMPTIONS**

1. All journal rows that enter the total are USD with non-negative amounts. The spec says the journal is USD but says nothing about refunds, negative amounts or other currencies.
2. Rows with an unknown price (the "unknown" count in the existing test) contribute 0 to the total. The spec does not say how they are counted.
3. Four decimal places are acceptable for the total, as in `CostTextOf`. Amounts below 0.00005 will still display as `$0`, which is the same kind of loss the finding describes.

**QUESTIONS**

4. Is `SpendingGroup.TotalUsd` in scope? The markup formats it as a number, and the spec does not say which culture it uses. If it still shows `0,0345` in ru-RU, the finding is not closed, yet the spec says "разметку не трогать".
5. What should the total show when there are no rows, or only unknown prices? The criteria define `$0` only for a zero sum, and the spec does not say whether a zero sum from real rows and an empty period should look the same.
6. Is `AppResources.CostFormat` a localized resource (.resx)? If so, its value depends on `CurrentUICulture`, and the `$` prefix could change under a Russian UI culture. The spec does not address this.

**RISKS**

7. The verification command `dotnet test --project ...` is probably invalid, since `dotnet test` takes the project path as a positional argument, not `--project`. It is also unverified that `scripts/check.sh` exists.
8. On Linux, if the environment runs with InvariantGlobalization, `ru-RU` is unavailable and the step-1 test cannot fail for the described reason. Culture availability needs to be confirmed before step 1.
9. The test sets `CurrentCulture` around an `await` in `RefreshAsync`. The culture must survive the continuation, and the `finally` restore must not affect other tests if they run in parallel. The spec does not mention parallelism.
10. The test uses rows dated "in the current month". Month-boundary and time-zone handling (local versus UTC) can make it flaky, and the plan fixes no date. The plan also has no test for the zero case that the criteria require.
