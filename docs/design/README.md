# Дизайн

Макеты и дизайн-система ImageGen (задача 051). Утверждённое владельцем — источник для вёрстки в MAUI и Avalonia (ADR 0006).

| Файл | Что | Статус |
|---|---|---|
| `research.md` | рекомендации платформ: раскладка по ширине, ввод, размер касания, соглашения iOS, Android, macOS, Windows, Linux, значки, шрифты | черновик, часть фактов по Apple не сверена с первоисточником |
| `directions.html` | три направления стиля: чат на десктопе и телефоне, светлая и тёмная тема | выбраны все три как стили (ADR 0014); страница сохранена как история |
| `tokens.json` | токены трёх стилей в двух темах, шкала шрифтов, отступы, области нажатия, варианты разметки (W3C Design Tokens 2025.10) | утверждено 2026-10-28 |
| `prototype.html` | все экраны и дизайн-система; переключатели стиля, темы, платформы и экрана; читает `tokens.json`; опубликован: https://claude.ai/artifact/M9QzPf39KLkRFTnYBtCi6F | утверждено 2026-10-28 |
| `implementation.md` | справочник для вёрстки: ключи ресурсов `Ig*`, варианты разметки как ресурсы, шрифты, значки Lucide, ширина окна, порядок кнопок | утверждено 2026-10-28 |
| `screenshots/` | снимки экрана чата: `chat-<desktop\|phone>-<a\|b\|c>-<light\|dark>.png` (Windows и iOS) | снимки утверждённой версии |

`directions.html` и `prototype.html` — тело страницы без `<!doctype>` и `<head>`: обёртку добавляет публикация артефакта. Локально открывается в браузере как есть (браузер достроит документ).

`prototype.html` загружает `tokens.json` запросом, поэтому из файла (`file://`) не открывается: `python3 -m http.server` в `docs/design/`, затем http://localhost:8000/prototype.html.

Контраст всех шести палитр проверяется таблицей на экране «Дизайн-система» прототипа.
