# Дизайн

Макеты и дизайн-система ImageGen (задача 051). Утверждённое владельцем — источник для вёрстки в MAUI и Avalonia (ADR 0006).

| Файл | Что | Статус |
|---|---|---|
| `research.md` | рекомендации платформ: раскладка по ширине, ввод, размер касания, соглашения iOS, Android, macOS, Windows, Linux, значки, шрифты | черновик, часть фактов по Apple не сверена с первоисточником |
| `directions.html` | три направления стиля на выбор: чат на десктопе и телефоне, светлая и тёмная тема | на выборе у владельца |

`directions.html` — тело страницы без `<!doctype>` и `<head>`: обёртку добавляет публикация артефакта. Локально открывается в браузере как есть (браузер достроит документ).
