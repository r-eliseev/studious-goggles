# 0019. Мобильная оболочка

Статус: предложено
Допустимые статусы: предложено, принято, заменено на NNNN, отклонено
Дата: 2026-10-30

При принятии варианта B или C заменяет ADR 0006 в части MAUI.

## Контекст

Задача 094 проверила Android-голову Avalonia 12.1.4 на Linux, подключив реальные экраны и модели приложения. Release APK для `android-arm64` собирается и на 6 968 679 байт (6.65 МиБ) больше MAUI APK — меньше допустимых 10 МиБ. Устройство отсутствовало, поэтому запуск, Android KeyStore после перезапуска, клавиатура Send, TalkBack, навигация, галерея, память и производительность не проверены. iOS-голова только изучена по шаблону и официальной документации; сборка требует Mac с Xcode. Подробности: `docs/knowledge/avalonia-mobile.md`.

Обязательные критерии: голова собирается; запускается; тестовый ключ переживает перезапуск; клавиша Send отправляет сообщение; APK не больше MAUI + 10 МиБ. Сборка и размер подтверждены. Запуск, ключ и клавиатура не проверены.

## Решение

Рекомендуется вариант A: временно оставить две оболочки (MAUI и Avalonia), затем пересмотреть решение после ручных Android-проверок на устройстве. Для перехода к B или C сначала проверить пользовательские сценарии Avalonia на реальном Android, а для B — дополнительно собрать и проверить iOS на Mac.

## Альтернативы

- **A — две оболочки, MAUI и Avalonia.** Выигрываем: сохраняем работающие MAUI мобильные и Windows-сценарии, не принимая решение по APK-сборке без runtime-данных. Теряем: поддерживаем разметку экранов в обеих оболочках. Объём переноса сейчас нулевой; мобильные экраны и службы остаются в MAUI, Android-пробник Avalonia остаётся исследовательским.
- **B — Avalonia везде.** Выигрываем: одна разметка для Sessions, API key, Chat, Model Picker, Session Models, Session Parameters и Settings на Linux/Windows/macOS/Android/iOS. Теряем: нельзя опираться на текущие ручные проверки MAUI, нужны проверки Avalonia на всех мобильных платформах. Объём переноса: заменить MAUI головы Android/iOS/Windows, завершить системный Back, клавиатуру, диалоги, clipboard и picker; реализовать и проверить Android KeyStore, MediaStore, Windows DPAPI/папки, iOS Keychain/Photos, Mac Catalyst и жизненный цикл.
- **C — Avalonia на десктопе и Android, MAUI только на iOS.** Выигрываем: убираем Android-разметку MAUI, сохраняя iOS оболочку до проверки Avalonia iOS. Теряем: остаются два мобильных UI-стека и двойная разметка iOS. Объём переноса: заменить MAUI Windows/Android головы на Avalonia, завершить/проверить Android-службы и сохранить MAUI iOS; общий экранный слой остаётся в Presentation.

## Последствия

До ручной проверки Android и iOS рекомендация не меняет принятое решение о двух оболочках. Результат сборки снижает риск по Android packaging и размеру, но не подтверждает работу на устройстве. Неизвестные проверки перечислены в `docs/knowledge/avalonia-mobile.md` и переданы в ручную задачу 140.
