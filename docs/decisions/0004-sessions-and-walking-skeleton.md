# 0004. Сессии с ассистентом и ходячий скелет на OpenRouter

Статус: принято
Допустимые статусы: предложено, принято, заменено на NNNN, отклонено
Дата: 2026-10-27

## Контекст
Владелец изменил основной сценарий: вместо композера с промптом и набором моделей пользователь работает в чате с ассистентом, а набор моделей становится настройкой сессии (`docs/specs/chat-sessions.md`). Первая версия должна быть ходячим скелетом: минимум функций, но все системы (секреты, каталог, ассистент, генерация, хранилище, UI) работают от начала до конца. Задачи скелета должны выполняться слабыми моделями без трактовок.

## Решение
- Основная единица работы — сессия (чат). Прогон — один запуск промпта на моделях сессии с общими сидами. Генерация хранит точный промпт, модель и сид.
- Ассистент — LLM OpenRouter с одним инструментом `generate_images(prompt)`. Ответ без вызова инструмента считается текстом пользователю (в том числе вопросом). Генерация запускается сразу.
- Скелет (v0.1): только OpenRouter и только MAUI (Windows). Провайдер в скелете описан узким интерфейсом `IImageGenerator.GenerateAsync` (синхронная модель OpenRouter). Контракт submit/watch из ADR 0003 вводится вместе с fal и Replicate; до этого ADR 0003 остаётся предложением.
- События генераций в скелете — обычное событие .NET `GenerationUpdated` у singleton-сервиса; MAUI переносит их в UI-поток. Подписка через `Channel` из `docs/architecture.md` откладывается до Web-оболочки.
- Тесты: xUnit v3 и NSubstitute для подмен.
- Пакеты и версии зафиксированы в `ImageGen/Directory.Packages.props` (задача 001).

## Альтернативы
- Композер с наборами моделей из основной спецификации: владелец выбрал чат.
- Сразу полный контракт ADR 0003 в скелете: усложняет первую версию ради провайдеров, которых в ней нет.
- Moq вместо NSubstitute: владельцу всё равно; NSubstitute проще читается в тестах.

## Последствия
Проще: короткий путь до работающего приложения, понятные задачи. Сложнее: при добавлении fal и Replicate придётся расширять `IImageGenerator` до контракта ADR 0003 и переводить события на подписку; восстановления заданий после перезапуска в скелете нет (только пометка «Interrupted»).
