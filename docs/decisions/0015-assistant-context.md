# 0015. Контекст ассистента: бюджет по контексту модели и сводка в отдельной таблице

Статус: принято
Допустимые статусы: предложено, принято, заменено на NNNN, отклонено
Дата: 2026-10-28

## Контекст
Сейчас ассистент получает последние 20 сообщений сессии (S2.6). Длинная сессия может не поместиться в контекст модели, а ранние договорённости (стиль, отказы) теряются. Задача 027; решения владельца — в её «Комментариях» и в `docs/specs/assistant-context.md`.

## Решение
1. Бюджет запроса считается от `ChatModel.ContextLength` (весь контекст модели, без потолка), оценка токенов — по длине текста с поправкой по `usage.prompt_tokens` последнего ответа (`docs/specs/assistant-context.md`, C1–C2).
2. Старая часть истории сжимается в одну скользящую сводку на сессию той же моделью ассистента, в фоне после ответа (C3).
3. Хранение: таблица `conversation_summaries`, одна строка на сессию (перезаписывается): `session_id` (PK, FK `sessions(id)` `ON DELETE CASCADE`), `text`, `covers_up_to_message_id`, `provider_id`, `model_id`, `cost_usd` (NULL, если провайдер не сказал), `created_at`. Новая миграция (ADR 0002), `0001_initial.sql` не меняется.
4. Логика без ввода-вывода (бюджет, выбор сообщений, укорачивание) — чистые классы в `ImageGen.Core/Context/`; ввод-вывод — в `ConversationSummaryService` и репозитории.
5. Каталог чат-моделей остаётся в памяти (`ChatModelCatalogService`): переносить в SQLite не нужно, `ContextLength` уже там.

## Альтернативы
- **Потолок бюджета (16 или 32 тыс. токенов)** ради цены — владелец выбрал весь контекст модели.
- **Сводка перед запросом** — свежее, но ответ ждёт два вызова модели; владелец выбрал фон.
- **Сводки цепочкой (по одной на кусок истории)** — точнее, но сложнее хранить и собирать; одна скользящая сводка достаточна для одного пользователя.
- **Сводку хранить сообщением в `chat_messages`** — смешивает служебный текст с перепиской и ломает фильтры ленты.

## Последствия
- Длинные сессии дороже: каждое сообщение несёт столько истории, сколько помещается в окно модели. Цена сводок сохраняется для экрана расходов (021).
- Нужен разбор `usage.prompt_tokens` в клиентах OpenRouter, OpenAI- и Anthropic-совместимых.
- Константа `AssistantPrompts.HistoryMessageCount` (20) становится минимумом дословных сообщений.
