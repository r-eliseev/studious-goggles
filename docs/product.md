# Продукт: ImageGen

Полная функциональная спецификация: `docs/specs/image-client.md` (функции F1–F10, экраны, сущности). Здесь только цели, границы и решения владельца, которые в спецификацию не вошли. Источник добавлений: рукописные заметки владельца от 2026-10-27, пересказанные ниже.

## Зачем нужен проект
Один клиент для генерации изображений через fal.ai, Replicate и OpenRouter. Пользователь подключает свои ключи (BYOK) один раз, отправляет один промпт сразу в несколько моделей и видит результаты рядом с ценой и временем. Результат сохраняется у пользователя сразу, потому что ссылки провайдеров истекают.

## Для кого
Один пользователь со своими ключами (решено: пользователь всегда один). В Web-варианте вход по форме, пароль задаётся переменной окружения.

## Принципы (из спецификации)
- BYOK: приложение не стоит между пользователем и провайдером по деньгам.
- Один промпт, много моделей: параллельный запуск — основной сценарий.
- Единые параметры переводятся в параметры каждого провайдера, неподдерживаемое показывается явно.
- Результат не теряется: сохраняется локально сразу после готовности.
- Прозрачность: провайдер, модель, параметры, время и цена видны у каждого запуска; фильтрация провайдером — отдельное состояние.
- Модерация провайдеров не обходится.

## Решения владельца (заметки, схема «ядро + оболочки»)
Ядро (Core) не зависит от UI и состоит из трёх частей:
- **Provider**: fal, Replicate, OpenRouter.
- **Generation**: Text2Img, Img2Img, Img2Text.
- **Config**: Secrets (секреты) и Preferences (настройки).

Оболочки (UI) над одним ядром:
- Android / iOS;
- Windows / Linux / macOS;
- Web API + статический Vue-фронт.

Дополнительные требования из заметок:
1. Автоподгрузка списка моделей у провайдеров.
2. Зашифрованное хранилище секретов.
3. Простая веб-авторизация: пароль задаётся переменной окружения.
4. Поддержка Docker (в первую очередь для Web API + Vue).
5. Расширение промпта (улучшение по просьбе; в спецификации это F4.8, P2, «до и после», решает пользователь).
6. Собственный репозиторий результатов (хранилище результатов под нашим контролем, не только файлы на диске).
7. Android: сохранение файлов в галерею.
8. Добавление моделей через конфиг (в спецификации F2.5: модель fal или Replicate по идентификатору).

Решено 2026-10-27: Img2Text (текстовое описание или промпт по готовой картинке) входит в первую версию; «свой репозиторий результатов» — локальная БД + файлы за интерфейсом в Core; Linux отложен (MAUI его не поддерживает); пересмотрено 2026-10-28 — Linux-десктоп даёт Avalonia-оболочка (ADR 0006). Остальное неоднозначное: `docs/status.md`, «Открытые вопросы».

## Сессии с ассистентом (решение 2026-10-27)
Основной сценарий — чат, как в ChatGPT: пользователь описывает картинку, ассистент (LLM через OpenRouter) составляет промпт и сразу запускает генерацию, по просьбе меняет промпт и запускает снова, при необходимости переспрашивает. Список моделей и число запусков на модель — настройки сессии, их можно менять в любой момент. Каждая генерация хранит точный промпт, модель и сид, её можно повторить, перегенерировать с новым сидом или поправить промпт вручную. Подробно: `docs/specs/chat-sessions.md`, ADR 0004.

Первая версия — ходячий скелет на OpenRouter и MAUI (Windows) с минимумом функций, но со всеми работающими системами. Базовый язык интерфейса — английский.

## Границы: что делаем
Первая версия по спецификации: генерация из текста, редактирование по референсам, параллельный запуск и сравнение, галерея, учёт расходов. Плюс решения владельца выше, в той мере, в какой они не противоречат спецификации.

## Границы: что не делаем
Видео и аудио, обучение LoRA, синхронизация между устройствами, локальные модели (ComfyUI), редактор холста с масками, многопользовательский режим, обход модерации провайдеров, скрытая подмена промпта или модели (F9.4).

## Термины
- **Провайдер**: fal.ai, Replicate или OpenRouter.
- **Группа запусков**: один нажатый «Запустить»; содержит по заданию на модель.
- **Задание**: запуск одной модели в группе; состояния: в очереди, идёт, готово, ошибка, отменено, отфильтровано.
- **Набор моделей**: именованный список моделей для параллельного запуска.
- **Core / ядро**: библиотека без UI-зависимостей (провайдеры, генерации, конфигурация).
- **Оболочка (head)**: приложение над ядром: MAUI, Web API + Vue.
- **BYOK**: свои ключи пользователя.
