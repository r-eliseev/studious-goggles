# Повтор запроса после ошибки ассистента

## Описание
Решение владельца по 074 (2026-10-28): у сообщения об ошибке ассистента (нет сети, лимит, неверный ключ — S2.5) кнопка «Try again» заново отправляет ассистенту последнее сообщение пользователя. Сообщение об ошибке остаётся в истории; новое сообщение пользователя не создаётся. Обе оболочки.

Макеты: `docs/design/prototype.html` (https://claude.ai/artifact/M9QzPf39KLkRFTnYBtCi6F), справочник вёрстки: `docs/design/implementation.md`. Решения владельца — задача 074, «Комментарии».

Зависит от: 068.
Среда: Linux или Windows.

## Критерии готовности
Детализировать при планировании (план — под небольшую модель): кнопка только у последней ошибки, недоступна во время ответа ассистента, повтор после перезапуска приложения, правка `docs/specs/chat-sessions.md` S2.5.
