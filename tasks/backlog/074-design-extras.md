# Новые функции с макетов

## Описание
На макетах задачи 051 есть элементы, которых нет в приложении. Это не вёрстка, а новые функции; каждой нужна своя спецификация или правка `docs/specs/chat-sessions.md`. Владелец решает, что из этого делать и в каком порядке; после решения задача делится на отдельные задачи.

Справочник: `docs/design/implementation.md` (ключи ресурсов, значения, шрифты, значки — дословно оттуда); токены: `docs/design/tokens.json`; макеты: `docs/design/prototype.html` (открыть: `python3 -m http.server` в `docs/design/`, затем http://localhost:8000/prototype.html; опубликованная версия — https://claude.ai/artifact/M9QzPf39KLkRFTnYBtCi6F); решение: ADR 0014.

Список (экран макета — что):
1. Список сессий — поиск по сессиям; переименование (S1.2 говорит «позже»); число прогонов в строке; клик по примеру в пустом состоянии создаёт сессию с этим текстом.
2. Чат — «Try again» у ошибки ассистента (повторить последний запрос, S2.5).
3. Карточка — «Details» у ошибки (исходный текст ошибки провайдера); «Other model…» у отфильтрованной (F-раздел основной спецификации, «Состояния карточки задания»); «Copy prompt» (пересекается с 055); «Save image as…» / «Save to Photos» / «Save to gallery» (пересекается с 029 — Android).
4. Прогон — строка о непереданных параметрах под промптом сейчас на каждой карточке; на макете — одна на прогон (обобщение по моделям).
5. Настройки — «Logs: Open folder» (сделано в 065, если владелец не против).

Зависит от: решений владельца.
Среда: —.
