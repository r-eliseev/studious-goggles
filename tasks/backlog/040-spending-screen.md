# Экран расходов и лимиты

## Описание
Раздел «Расходы» по макету: за день, неделю, месяц, по провайдеру и модели (F8.3), месячный лимит и порог «предупредить, если запуск стоит больше X» с проверкой перед запуском (F8.4). Графики: при необходимости `Syncfusion.Maui.Toolkit` по решению владельца, с ADR.

Зависит от: 010, 018.

## Критерии готовности
- Предупреждение показывается до запуска, когда оценка группы превышает остаток лимита.
- Фактические и оценочные суммы различимы.
