# Список сессий: поиск, переименование, число прогонов

## Описание
Решение владельца по 074 (2026-10-28): в списке сессий сделать поиск по названию (поле «Search sessions» над списком), переименование сессии (пункт Rename в меню строки: правый клик на десктопе, долгое нажатие на телефоне; меняет `docs/specs/chat-sessions.md` S1.2 — «переименование позже») и число прогонов в строке («2 min · 3 runs»). Обе оболочки.

Макеты: `docs/design/prototype.html` (https://claude.ai/artifact/M9QzPf39KLkRFTnYBtCi6F), справочник вёрстки: `docs/design/implementation.md`. Решения владельца — задача 074, «Комментарии».

Зависит от: 067 (общий список сессий `SessionsListView`).
Среда: Linux или Windows (Avalonia — headless-тесты; MAUI — сборка Android, ручная проверка в 016).

## Критерии готовности
Детализировать при планировании (план — под небольшую модель, как 059–072): поиск без учёта регистра, пустой результат, переименование с проверкой пустого названия, хранение нового названия (`SessionRepository`), число прогонов из БД без лишних запросов на каждую строку, правка спецификации S1.2.
