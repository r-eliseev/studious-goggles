# Контракт провайдера и тестовая инфраструктура

## Описание
`IImageProvider`, `ProviderJobRequest`, `ProviderJobHandle`, `JobUpdate`, `CancelOutcome` по `docs/decisions/0003-provider-contract-and-jobs.md`. Регистрация HTTP-клиентов через `IHttpClientFactory`, общий разбор ошибок HTTP в `ProviderErrorKind` (F9.1), вырезание ключей из текстов ошибок. Фейковый провайдер для тестов оркестратора и для разработки UI без ключей. Помощник тестов на подменённом `HttpMessageHandler`.

Зависит от: 002, 003.

## Критерии готовности
- Контракт и фейковый провайдер в ядре; фейковый подключается только явно, не в рабочей конфигурации.
- Разбор кодов 401, 402, 403, 404, 408, 429, 5xx и сетевых ошибок в `ProviderErrorKind` покрыт тестами.
- Ключ не виден в сообщении исключения, даже если провайдер вернул его в ответе (тест).
