# Каталог моделей и наборы

## Описание
`CatalogService`: единый каталог моделей всех подключённых провайдеров, автозагрузка списков у провайдеров (требование владельца 1) с кешем в БД, поиск и фильтры (провайдер, цена, референсы, формат, текст вместе с картинкой), карточка модели (F2.1–F2.3). `ModelSetService`: именованные наборы с порядком и быстрый выбор без набора (F3.1, F3.2).

Зависит от: 004, 006, 007, 008.

## Критерии готовности
- Каталог работает без сети по кешу и показывает дату обновления.
- Отключённый провайдер не даёт моделей в каталоге.
- Набор хранит порядок моделей; модель, пропавшая из каталога, остаётся в наборе с пометкой «недоступна».
- Тесты на фейковых провайдерах и временной БД.
