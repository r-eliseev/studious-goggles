# Провайдер OpenRouter

## Описание
Реализация `IImageProvider` для OpenRouter: проверка ключа, каталог из `GET /api/v1/images/models` (параметры, допустимые значения, цены), генерация `POST /api/v1/images` (ответ base64, `media_type`, `usage.cost`), референсы `input_references`, Img2Text через chat completions с картинкой на входе. Явной отмены нет: `CancelOutcome` «не поддерживается», отмена токеном прерывает ожидание.

Зависит от: 005.

## Критерии готовности
- Каталог разбирается в `ModelDescriptor` с ценой и единицей; тест на сохранённом образце ответа.
- Генерация возвращает байты картинки и фактическую цену из `usage.cost`.
- Отказ модерации даёт состояние «отфильтровано», а не ошибку.
- Img2Text возвращает текст и цену.
- Все вызовы покрыты тестами на подменённом `HttpMessageHandler`, реальных ключей в тестах нет.
