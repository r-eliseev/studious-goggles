# Провайдер Replicate

## Описание
Реализация `IImageProvider` для Replicate: создание предсказания, опрос (`starting`, `processing`, `succeeded`, `failed`, `canceled`), отмена, дедлайн `Cancel-After`, проверка ключа, возможности модели из схемы входа версии модели. Файлы результата живут час, поэтому скачиваются сразу.

Зависит от: 005.

## Критерии готовности
- Статусы приводятся к единой модели, логи передаются в `JobUpdate`.
- Отмена по id даёт «отменено».
- Схема входа превращается в `ModelCapabilities` (тест на образце).
- Цена считается по прайсу с пометкой «≈», если Replicate её не вернул.
- Тесты на подменённом `HttpMessageHandler`.
