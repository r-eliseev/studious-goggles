# Конфигурация: секреты, настройки, подключения

## Описание
Интерфейсы платформы `ISecretStore`, `ISettingsStore`, `IAppPaths` и сервис `ConnectionService` (F1.1–F1.3): ключ для каждого провайдера отдельно, проверка при сохранении через провайдера, статус «работает / неверный ключ / нет связи», маска по последним 4 символам, замена и удаление. Реализации в памяти для тестов.

Зависит от: 002.

## Критерии готовности
- Ключ не возвращается наружу целиком; читает его только провайдер в момент вызова.
- Ключ не попадает в журналы, `ToString()` и исключения (тест на подменённом логгере).
- Можно подключить любое подмножество провайдеров; статус и дата проверки сохраняются.
- Тесты `ConnectionService` на подменённом провайдере.
