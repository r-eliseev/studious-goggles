# Img2Text: описание по картинке

## Описание
Текстовое описание или промпт по готовой картинке (загруженной, из галереи, из результата) через оркестратор с видом `ImageToText` (F4.9). Провайдер и модель видны, стоимость учитывается как у обычного задания. Модели для Img2Text отбираются по возможностям из каталога.

Зависит от: 006, 012.

## Критерии готовности
- Результат хранится как текстовый результат задания с ценой.
- Ядро не подставляет текст в промпт само, только возвращает его.
- Тест полного пути на фейковом провайдере и на подменённом OpenRouter.
