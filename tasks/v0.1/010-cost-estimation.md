# Оценка и учёт стоимости

## Описание
`CostEstimator`: оценка до запуска по прайсу модели с учётом плана (число запросов, мегапиксели, картинки), признак «≈» для неточных единиц (токены, секунды GPU); фактическая цена после запуска, если провайдер её вернул; итог по группе (F4.4, F8.1, F8.2). `SpendingService` с суммами по заданию и группе.

Зависит от: 002, 009.

## Критерии готовности
- Оценка для каждой единицы цены покрыта тестами.
- Если фактической цены нет, хранится оценка с пометкой «≈».
- Итог группы складывается из фактических цен там, где они есть, иначе из оценок; у итога «≈», если есть хотя бы одна оценка.
