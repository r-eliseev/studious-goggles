# Хранилище: SQLite и файлы результатов

## Описание
Проект `ImageGen.Data` по `docs/decisions/0002-sqlite-ado-net.md`: помощник команд, миграции через `PRAGMA user_version`, репозитории групп, заданий (с `ProviderJobHandle`), результатов, расходов, наборов моделей, кеша каталога; файловое хранилище результатов в каталоге из `IAppPaths`. Проект `ImageGen.Data.Tests`.

Зависит от: 002.

## Критерии готовности
- Схема создаётся миграцией с нуля и обновляется с предыдущей версии (тест).
- SQL только с параметрами, колонки читаются по имени.
- Сначала пишется файл, потом запись; при старте находятся записи без файлов и файлы без записей.
- Удаление результата не удаляет запись о расходах (F7.7).
- Тесты на временной БД проходят на Windows и Linux.
