# Web API над сервисами ядра

## Описание
Эндпоинты над сервисами ядра (подключения, каталог, наборы, подготовка и запуск группы, отмена, повтор, Img2Text, галерея, файлы результатов, расходы) и поток событий группы для браузера. Выбор между SSE и SignalR оформить ADR (по умолчанию SSE: без лишних зависимостей во фронте).

Зависит от: 011, 012, 013, 024.

## Критерии готовности
- API не возвращает ключи, только маски.
- Поток событий переживает переподключение браузера: клиент получает текущее состояние группы.
- Файлы результатов отдаются только после входа.
- Контракт API описан (OpenAPI), тесты на основные сценарии.
