# Docker-образ Web-оболочки

## Описание
`Dockerfile` (многоэтапная сборка: node, dotnet publish, aspnet runtime, непривилегированный пользователь), `docker-compose.yml` с томом `/data` и переменной пароля, описание запуска в документации, сборка образа в CI (требование владельца 4).

Зависит от: 026.

## Критерии готовности
- `docker compose up` поднимает приложение, данные и секреты переживают пересоздание контейнера.
- Пароль задаётся только переменной окружения, в образе секретов нет.
- Образ собирается в CI.
