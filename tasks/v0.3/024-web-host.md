# Web-оболочка: хост, вход, секреты

## Описание
Проект `ImageGen.Web` (ASP.NET Core): вход по форме с паролем из переменной окружения и cookie-сессией (однопользовательский), `ISecretStore` на файле, зашифрованном Data Protection, ключи шифрования и данные в каталоге из конфигурации (в Docker — том `/data`), `GenerationService` как singleton в процессе сервера, восстановление заданий при старте. Проект `ImageGen.Web.Tests`.

Зависит от: 003, 004, 012.

## Критерии готовности
- Без входа API отвечает 401, кроме формы входа; неверный пароль не раскрывает подробностей, попытки ограничены по частоте.
- Пароль и ключи не попадают в журналы.
- Сервер не стартует без заданного пароля и пишет понятную причину.
- Тесты на `WebApplicationFactory`.
