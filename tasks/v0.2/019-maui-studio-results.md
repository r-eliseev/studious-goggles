# MAUI: сетка результатов и карточки заданий

## Описание
Низ Студии: группа с прогрессом и итоговой ценой, карточка на задание, которая занимает место сразу; состояния карточки по таблице спецификации (в очереди с позицией, идёт, готово, ошибка с причиной, отменено, отфильтровано); отмена задания и группы, повтор, «на другой модели» (F5.1–F5.5, F6.1, F6.5, F8.1, F8.2, F9.1, F9.2).

Зависит от: 012, 018.

## Критерии готовности
- Сетка не перестраивается при приходе результатов, порядок карточек равен порядку выбора моделей.
- Отфильтрованное задание показано отдельной карточкой с пояснением, а не ошибкой.
- Ошибки локализованы по `ProviderErrorKind`, исходный текст провайдера по нажатию.
- Статусы озвучиваются `SemanticScreenReader` и дублируются значками.
