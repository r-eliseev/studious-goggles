# MAUI: Img2Text

## Описание
Действие «описать картинку» для загруженной картинки, результата и картинки из галереи: выбор модели, запуск, показ текста, подстановка в промпт только по кнопке пользователя (F4.9).

Зависит от: 013, 018.

## Критерии готовности
- Провайдер, модель и цена описания видны.
- Текст не попадает в промпт без действия пользователя.
