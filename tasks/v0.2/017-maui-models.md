# MAUI: каталог моделей и наборы

## Описание
Раздел «Модели» и панель выбора моделей из композера по макету «Выбор моделей»: список, поиск и фильтры, карточка модели с параметрами, ценой и ограничениями, пометки (лицензия, «нельзя отключить фильтр»), выбор галочками, сохранение набора (F2.1–F2.3, F3.1, F3.2).

Зависит от: 011, 014.

## Критерии готовности
- Список из сотен моделей прокручивается без задержек (`CollectionView` с виртуализацией).
- Выбранные модели и набор передаются в Студию.
- Каталог открывается без сети по кешу.
