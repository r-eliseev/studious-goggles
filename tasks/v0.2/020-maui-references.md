# MAUI: референсы и редактирование по картинкам

## Описание
Референсные картинки в композере: выбор из файлов и галереи, вставка, ссылка, результат как референс; пометка моделей, которые не вмещают столько референсов, с предложением убрать лишние (F4.5, «Доработка» из сценариев). В спецификации F4.5 стоит P1, но редактирование по референсам входит в первую версию (`docs/product.md`), поэтому задача в v0.2.

Зависит от: 018.

## Критерии готовности
- Лимит референсов каждой модели учитывается в проверке перед запуском.
- Референс из результата берётся из локального файла, а не по ссылке провайдера.
